# Land Sales & Marketing Intelligence

Complete repository blueprint for an owned-land sales, marketing, CRM, analytics, comparison, recommendation, and automation platform.

Primary market: Texas. Florida is separated, with Zyphree Hills represented as its own property.

Stack:
- React + Vite + Tailwind CSS
- FastAPI + SQLAlchemy + PostgreSQL
- Alembic
- Redis
- Docker

Build order:
1. Database and migrations
2. Domain models and repositories
3. Backend services and APIs
4. Analytics and comparison engines
5. Automation and AI recommendations
6. Frontend modules
7. Authentication and permissions
8. Imports and external data adapters
9. Testing
10. Deployment and production hardening

This package is the complete file/folder blueprint. Add business logic module-by-module rather than putting intelligence inside the dashboard.
